6 Core Insights
Insight #1 · Architecture
Exceptional Offline-First Foundation
The SQLite → PostgreSQL sync pattern with BullMQ queues is production-grade. The 139 mobile tests cover SQLite CRUD with exponential backoff retry logic — a rare sophistication for SME-market apps. This unlocks rural adoption where connectivity is intermittent.
Insight #2 · Visualization Gap 🔴
Mobile Charts Are Absent
The web admin dashboard (Next.js) has rich visualizations, but the Expo mobile app currently shows static stat cards only. There are no sparklines, trend rings, or anomaly heatmaps in the React Native layer — despite Reanimated 4.x being installed and ready to drive them.
Insight #3 · AI Pipeline
Anomaly Detection Exists But Is Silent
The backend's Fastify routes include anomaly-flagging logic (invoice #0042, 4.2× average). On mobile, users only see a static "pending" status label. There is no visual spike chart or real-time push alert system connecting the AI signal to the trader's phone screen.
Insight #4 · Gamification Shell
Streak Infrastructure Partially Wired
The web dashboard renders streak counters (🔥 21 days), XP bars, and badge rows. The mobile screens expose a compliance tips section but lack the streak/XP gamification layer entirely. The Reanimated library is present — animation infrastructure exists to wire this in hours.
Insight #5 · USSD Gap
USSD Only in Web Simulator
The web dashboard has a slick USSD simulator panel but the mobile app has no native USSD integration hook. African networks allow apps to initiate USSD sessions via intent URIs on Android (tel:*347*TBR%23). This could onboard the 40M feature-phone traders the PRD targets.
Insight #6 · Performance
Bundle Size Has Room to Grow
The Expo build currently passes all gates but adding charting libraries risks crossing the 50MB sweet spot for Nigerian low-storage Android devices. Replacing a full Recharts bundle with a lightweight custom SVG renderer (≈8KB vs ≈120KB) is the right call for the target market.

AI Anomaly Alert (F2)
When the backend's anomaly detector flags an invoice, an Expo Push Notification fires immediately (even when app is backgrounded). Tapping the notification opens this screen — a purpose-built anomaly review view with a sparkline bar chart showing the invoice amount vs. 30-day rolling average.
  • Sparkline bar chart — 12 bars, last invoice highlighted in coral. Custom SVG renderer: ~2KB, no library dependency, renders in <16ms.
  • Penalty exposure calculation — NTAA §104: ₦200K + 100% VAT, shown clearly so the trader understands the financial stakes.
  • Single-screen decision — Approve sends to DigiTax MBS immediately. Void releases the IRN. No multi-step navigation.
  • Offline queue — If offline when notification fires, decision is stored in SQLite and executed on next sync.
// backend/src/services/anomaly.service.ts export async function detectAnomaly(invoice: Invoice) { const avg = await get30DayAverage(invoice.userId); const ratio = invoice.totalAmount / avg; if (ratio > 3.0) { await queue.add('push-anomaly', { userId: invoice.userId, invoiceId: invoice.id, ratio: ratio.toFixed(1), penalty: calcPenalty(invoice), sparkData: await getLast12Invoices(invoice.userId), }); } } // mobile/src/screens/AnomalyReviewScreen.tsx const SparklineChart = ({ data, flaggedIndex }) => { const max = Math.max(...data); return ( <View style={styles.sparkContainer}> {data.map((v, i) => ( <View key={i} style={[ styles.sparkBar, { height: `${(v/max)*100}%` }, i === flaggedIndex && styles.sparkBarHi ]}/> ))} </View> ); };

Gamified Streak System (F3)
Drawing from Duolingo's habit science: daily filing becomes a ritual, not a chore. The streak counter resets at midnight Lagos time if no invoice or payment action occurs. The XP system is simple — each compliant action awards points that unlock badges publicly visible in the Lagos leaderboard.
  • Reanimated confetti on streak milestone (7d, 14d, 30d). Particle count dynamically scales to available memory (50 particles on low-end, 120 on mid-range).
  • SQLite-stored streak — survives offline for 48h with grace period logic, syncs with backend on reconnect.
  • Lagos Leaderboard — Opt-in anonymised ranking among state-level traders, driving social proof and peer compliance.
  • Badge system — "NRS Star" badge (zero penalties 90 days) can be shared as a WhatsApp sticker — viral marketing for the platform.
// mobile/src/hooks/useStreak.ts export function useStreak() { const [streak, setStreak] = useState<StreakData>(null); useEffect(() => { const loadStreak = async () => { const data = await db.getFirst( 'SELECT * FROM streak WHERE userId = ?', [userId] ); const daysSinceLast = daysDiff(data.lastFiledAt, new Date()); if (daysSinceLast > 1) { // Streak broken — reset with grace period await db.runAsync('UPDATE streak SET count=0...'); } setStreak(data); }; loadStreak(); }, []); return { streak, xp: streak?.xp ?? 0 }; }

Tax Breakdown Donut (F4)
A custom SVG donut chart — drawn with static circle arcs computed at render time — gives the trader an immediate grasp of where their money goes. The implementation deliberately avoids Recharts or Victory Native, keeping the mobile bundle lean. The full renderer is under 60 lines of TypeScript.
  • Custom SVG arcs — stroke-dasharray computed from slice percentages. Zero third-party charting dependency, ~3KB of code.
  • Tap-to-drill — tapping a slice or legend row opens a bottom sheet with monthly trend bars for that tax type and the relevant NTA 2025 section.
  • Animated entrance — Each arc strokes in sequentially using Reanimated's withTiming, creating a satisfying "filling" reveal on load.
  • Offline data — Totals aggregated from local SQLite invoice records. Always available. Syncs to reconcile when online.
// mobile/src/components/DonutChart.tsx interface Slice { label: string; pct: number; color: string; } const buildArcs = (slices: Slice[], r=48, cx=65, cy=65) => { const C = 2 * Math.PI * r; // circumference let offset = 0; return slices.map(s => { const dash = (s.pct / 100) * C; const arc = { dash, gap: C - dash, offset }; offset -= dash; return { ...s, ...arc }; }); }; export const DonutChart: React.FC = ({ slices }) => { const arcs = buildArcs(slices); return ( <Svg width="130" height="130"> {arcs.map((a, i) => ( <AnimatedCircle key={i} cx="65" cy="65" r="48" fill="none" stroke={a.color} strokeWidth="20" strokeDasharray={`${a.dash} ${a.gap}`} strokeDashoffset={a.offset} transform="rotate(-90 65 65)" /> ))} </Svg> ); };

Install expo-notifications. Register Expo Push Token on auth. Backend stores token in users.pushToken. BullMQ worker calls sendPushNotification() when anomaly score exceeds threshold.

3 Iteration Alternatives
01
Lite Mode — Feature Phone PWA PRIORITY
A stripped-down Progressive Web App targeting Nigerian feature phones (Android Go, KaiOS). No React Native — pure HTML/CSS/vanilla JS. The health score renders as a text percentage. Streak is a simple counter. Donut is a text table: "VAT: 42% · ₦84.5K". Load target: <30KB total, <1s on 2G. Serve via Cloudflare Pages. This directly serves the 40M traders the PRD explicitly cites but who cannot install APKs. The USSD bridge (F6) complements this tier — app shows "Dial *347*TBR# to create an invoice without data."

Effort: 2 weeks · Dependencies: None · Reach: 10× the current addressable market
02
AI Tax Advisor in Pidgin PHASE 2
Integrate the Claude API (claude-haiku-4-5 for low latency) with a TaxBridge-specific system prompt covering NTA 2025 and the user's current invoice context. Interface: WhatsApp-style chat bubble on a dedicated "Ask TaxBridge" screen. Input in English or Pidgin, response always in Pidgin with formal English option. Cached responses stored in SQLite for frequent questions ("How much VAT I go pay on ₦500K?" → cached result served offline). Rate-limited to 10 queries/day on the free tier to manage API costs.

Effort: 3 weeks · Dependencies: Claude API key, streaming response handling · NPS Impact: Estimated +18 points based on comparable fintech chat integrations
03
Multi-Business Dashboard FUTURE
Nigerian traders commonly run 2–3 ventures simultaneously (e.g. a textile stall, a food business, and a phone repair shop). The current TaxBridge model assumes one TIN per user. Iteration 3 extends the SQLite schema and UI to support switching between businesses within a single app session — each with its own health ring, streak, and invoice list. A business switcher tab bar replaces the current single-profile model. This positions TaxBridge as the consolidated tax OS for informal traders rather than a single-entity tool.

Effort: 6 weeks · Dependencies: Backend multi-tenancy refactor, new Prisma schema · Revenue model: Premium tier at ₦3,500/month unlocks 3 businesses
